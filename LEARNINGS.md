# LEARNINGS (append 2-4 lessons per batch; read before every batch)
- Headline line-height below 1.2 made descenders (y, g) touch the next line. Keep >= 1.2 + text-wrap: balance.
- Phone mockup content must fit: coffee stamp grid (5 x 56px) overflowed a 280px card; button at bottom got clipped. Count widths before building; check_gfx.js now flags both.
- Dense content beats sparse: empty halves looked unfinished. Scale UI rows (padding 15-25px, font 17-22px) to fill the space.
- Kishan likes: Open Peeps characters when meaningful, comic strips, spot-the-problem, Swiss grid carousel, retro US palettes. Avoid floating sitting poses.
- Rotated elements give false text-overlap flags in check_text.js; confirm visually with a 1:1 crop.
- Best reel performers on the profile were specific Indian micro-niches with one daily operational pain (tent house, solar installer, car wash, furniture, brick kiln): keep posts that specific.
- (b001) Anton headlines: its tall glyphs overlap a kicker 10px above (check_text OVERLAP). Give Anton h1 margin-top >= 30px and inner Anton labels >= 16px top margin.
- (b001) Stretched cards with flex:1 leave dead white middles (kanban cards, list cards). Fix by adding real rows (3rd card, extra list items, form fields) and bigger type (titles 24-26px, body 19-21px) rather than more padding.
- (b001) Drive upload: write each text to work/drive/NNNN.txt and pass base64Content as "sha256:<hex>:<abs path>" (tools/drive_txt.py builds them). Fast, no retyping.
- (b001) Worked well: one hero object per single (calendar heat-grid, kanban board, timeline). Next: try a paper document mock (receipt/job card), a split before/after with a diagonal cut, and a comic strip.
- (b002) Never name a class .lg (logo class in BASE): it collapsed a "visit log" box and shrank the logo. Avoid BASE names: pg, wm, vis, ft, lg, cta, ib, sub, grain.
- (b002) Badge with fixed height + border + line-height = height causes VOVERFLOW. Center badge numbers with display:flex + line-height:1.
- (b002) Any rotate() on text cards triggers false OVERLAP in check_text; use offsets (alternating margins) for a sticker feel instead.
- (b002) Biggest recurring weakness: tall stretched columns with little content. Plan content density per card BEFORE coding (5+ rows per list card, "good for" boxes, logs), and set side-point cards to flex:1 with big type. CTA slides: keep the question card large (34-40px) so the slide is not half empty.
- (b003) Class name clashes inside one post bite too: `.g` (grid) collided with `.g` (green pill) and stretched pills into big boxes. Prefix layout classes (rg, vlog) and keep status pills as .pill-*.
- (b003) When fg (page text colour) is white but the header sits on a light area, set .wm/h1/.sub colours explicitly, and set the mockup's inner color, or text vanishes (tiles post).
- (b003) List columns in tall cards: make rows flex:1 with align-items:center so items spread evenly instead of leaving an empty bottom.
- (b003) New ideas that worked: floor-plan grid (PG), myth-vs-fact with strikethrough, ticket-stub cards via CSS mask, marker whiteboard with red numbered rings. Next: try an isometric/3D-ish card stack, a big receipt mock, and a before/after slider handle.
- (b004) CTA slides with a peep keep coming out half empty at the top. Fix pattern: peep w~400 h~650 + option cards with 34-38px padding and 24-26px text; or add a scene object above (cloud/sun) in single-hero slides.
- (b004) Pure-CSS "henna" rings looked like tree rings. Small repeated motifs (dot + ring + conic rays, 64px tile, masked by the skin colour) read as a pattern; prefer tiled motifs over one big radial.
- (b004) 3D tilt (perspective + rotateX 24deg) on a data board passed check_text/check_gfx cleanly and added depth; pair it with a flat answer card overlapping the bottom edge.
- (b004) Next to try: a real before/after slider handle, a stacked "paper pile vs one app" isometric, and a dark-mode dashboard single for a US niche.
- (b005) Before/after slider (two halves + orange divider + round handle) is a strong scroll-stopper for "paper vs app" topics; keep both halves with the same row count so rows line up across the handle.
- (b005) Dark dashboards: keep sample numbers internally consistent (bar chart days add up to the weekly KPI) and label tiles "sample". Use grid rows like auto 1.5fr .6fr so short rows don't become empty tiles.
- (b005) Overlapping rotated paper cards passed checks when each card is absolutely positioned inside an overflow:hidden box; good for "pile of paper" visuals.
- (b005) Next: isometric shelf/stock illustration for a retail niche, a map-route single for an Indian cab operator, and a split-screen chat vs form comparison.
- (b006) Anton again: big Anton numbers (110px) and Anton card titles flagged OVERLAP with the line below. Use line-height >= 1.25 for Anton/Lora display numbers plus margin-bottom 6px under Anton titles; add margin-top 14px to rows right under an Anton h1.
- (b006) "Front of card" mocks leave a dead middle when only a headline + QR. Fill with a small visual row (CSS dish circles), a dashed "this week" box and hours, so the card reads as a real printed insert.
- (b006) New techniques that worked: CSS kraft bag + die-cut sticker (dashed inner border), conic-gradient ring gauges per outlet row, hazard-tape stripe bands (repeating-linear-gradient -45deg), frosted glass cards (backdrop-filter) over blurred blobs. Next: try an isometric shelf, a paper calendar tear-off, a split "owner's day vs customer's day" timeline.
- (b006) Side-text + mockup "fix" panels: give the text column 320px and Anton 54px, and raise form field text to 17-18px; 15-16px form text looks tiny in the feed.
- (b007) Transformed (rotateX/rotateZ) isometric grids report a bigger bounding box than they look: size them to ~60% of the box (330px in a 470px panel) or check_gfx flags ESCAPES.
- (b007) Cards in a 2x2 or stacked list must scale type with the card: 38px titles, 22px body, 24px bars. Small 18px text inside tall cards reads as empty in the feed.
- (b007) Map callout tags must sit fully inside open map space, not at the right edge (looked clipped). Put tags where there is 250px+ of free area and point with an arrow.
- (b007) New techniques that worked: isometric desk floor, progress rail across carousel slides, folded paper document with a crease gradient, OMR bubble sheet, top-down CSS yard map. Next: a tear-off paper calendar, an isometric shelf for retail stock, an owner's-day vs customer's-day split.
- (b008) Never reuse a container class name as a variant class: `.cat` (catalogue wrapper) also styled the cat-eye frame and broke the grid. Prefix variants (ce, rnd) or use .fs-* names.
- (b008) A label pill set to inline-block still stretches full width inside the flex-column .pg. Add align-self:flex-start to kicker/step badges.
- (b008) Hero illustration panels (clothes rail, truck) leave dead space when given flex:1. Size them to content (flex:none + padding) and give the spare height to the data cards below, or fill with a guide line (dashed "half truck" level).
- (b008) Pinned/stacked paper notes: stagger left/right with vertical gaps so no note covers another note's text; check the bottom caption bar is clear. New techniques that worked: SVG hanger rail, CSS truck load gauge, cork texture, CSS bubble-tea cup, tablet mockup. Next: tear-off calendar, isometric shelf, owner's-day vs customer's-day split.
- (b009) "Field + why" checklist cards looked empty in the middle. Adding a small "On chat: vague message → question" bubble between the title and the form answer filled them and made the point stronger (bad vs good in one card). Reuse for any checklist carousel.
- (b009) Big display dates (Crimson 170px) trigger OVERLAP with the label above/below at line-height 1.2; use 1.35 and a 6px margin-top.
- (b009) Keep sample data consistent with the headline claim: the Gantt chart had Tractor 2 booked on Thursday while the card said it was free. Re-read every number against the headline before saving.
- (b009) New techniques that worked: tyre stack with repeating tread stripes, tear-off calendar with zigzag clip-path, Gantt week chart, cardboard box stack with tape strips. Next: isometric shelf for retail stock, owner's-day vs customer's-day split, map with route pins for a delivery niche.
- (b010) Comment pins on a mockup: place them inside a relative wrapper the same size as the design and aim each pin at the thing the comment is about, never over text. Check pin-to-comment meaning in a 1:1 crop.
- (b010) Patterned objects vanish on a same-colour panel (indigo-dot kurti on indigo). Put patterned illustrations on a neutral panel and vary the pattern colours.
- (b010) Building cross-section read too small at 640px with sky dead space; 800px wide with 200px units and 18px tags fills the panel. Illustrations should take 70%+ of their panel.
- (b010) New techniques that worked: annotated proof with crop marks, side-by-side without/with timelines, clip-path garment silhouettes with CSS block-print patterns, CSS building cross-section. Next: isometric shelf, map with route pins, receipt-style comparison.
- (b011) Headline orphans ("board.", "godown.") happen when the 2nd line is long; text-wrap:balance does not help across a <br>. Put a manual <br> in long accent lines and drop h1 to 58-60px.
- (b011) Zero-height lines (border-top dimension lines) make their labels ESCAPE. Draw lines as a box with a centred background stripe (linear-gradient 0 50%/100% 2px) so the label sits inside the box. `zoom:1.2` on a fixed-px illustration is a clean way to scale it up to fill its panel.
- (b011) Sample dates must make sense with today's date: a "next visit" in a past month looks wrong. Check weekday + month against the real calendar and keep the year board's done/booked dots consistent with it.
- (b011) In a column card, every child with flex:1 shares spare height, so a short notes box became a huge empty slab. Give text boxes flex:none and let list/check rows take the height (flex:1 rows, 26-28px text). New techniques that worked: CSS material swatches (wood grain, terrazzo, linen, brass), measuring-tape band, blueprint plan, sheet stacks with a reorder line.
- (b012) Anton title + small subline in cards still flags OVERLAP at 1.3; use line-height 1.35 + margin-bottom 6px on every Anton card title from the start.
- (b012) Shoe boxes as tall grid cells read as lockers. Real-world objects need the right aspect ratio: shoe boxes wide and short (3 cols x 6 rows), label on the side. Check that the illustration reads as the object in a 1:1 crop.
- (b012) Keep every number and status in a carousel consistent across slides (floor plan "not done" = report "skipped: room locked"; Friday-only task left open on a Tuesday). It makes the story believable.
