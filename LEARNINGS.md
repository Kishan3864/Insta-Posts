# LEARNINGS (append 2-4 lessons per batch; read before every batch)
- Headline line-height below 1.2 made descenders (y, g) touch the next line. Keep >= 1.2 + text-wrap: balance.
- Phone mockup content must fit: coffee stamp grid (5 x 56px) overflowed a 280px card; button at bottom got clipped. Count widths before building; check_gfx.js now flags both.
- Dense content beats sparse: empty halves looked unfinished. Scale UI rows (padding 15-25px, font 17-22px) to fill the space.
- Kishan likes: Open Peeps characters when meaningful, comic strips, spot-the-problem, Swiss grid carousel, retro US palettes. Avoid floating sitting poses.
- Rotated elements give false text-overlap flags in check_text.js; confirm visually with a 1:1 crop.
- Best reel performers on the profile were specific Indian micro-niches with one daily operational pain (tent house, solar installer, car wash, furniture, brick kiln): keep posts that specific.
- (b001) Anton headlines: its tall glyphs overlap a kicker 10px above (check_text OVERLAP). Give Anton h1 margin-top >= 30px and inner Anton labels >= 16px top margin.
- (b001) Stretched cards with flex:1 leave dead white middles (kanban cards, list cards). Fix by adding real rows (3rd card, extra list items, form fields) and bigger type (titles 24-26px, body 19-21px) rather than more padding.
- (b001) Drive upload: write each text to work/drive/NNNN.txt and pass base64Content as "sha256:<hex>:<abs path>" (tools/drive_txt.py builds them). Fast, no retyping.
- (b001) Worked well: one hero object per single (calendar heat-grid, kanban board, timeline). Next: try a paper document mock (receipt/job card), a split before/after with a diagonal cut, and a comic strip.
- (b002) Never name a class .lg (logo class in BASE): it collapsed a "visit log" box and shrank the logo. Avoid BASE names: pg, wm, vis, ft, lg, cta, ib, sub, grain.
- (b002) Badge with fixed height + border + line-height = height causes VOVERFLOW. Center badge numbers with display:flex + line-height:1.
- (b002) Any rotate() on text cards triggers false OVERLAP in check_text; use offsets (alternating margins) for a sticker feel instead.
- (b002) Biggest recurring weakness: tall stretched columns with little content. Plan content density per card BEFORE coding (5+ rows per list card, "good for" boxes, logs), and set side-point cards to flex:1 with big type. CTA slides: keep the question card large (34-40px) so the slide is not half empty.
- (b003) Class name clashes inside one post bite too: `.g` (grid) collided with `.g` (green pill) and stretched pills into big boxes. Prefix layout classes (rg, vlog) and keep status pills as .pill-*.
- (b003) When fg (page text colour) is white but the header sits on a light area, set .wm/h1/.sub colours explicitly, and set the mockup's inner color, or text vanishes (tiles post).
- (b003) List columns in tall cards: make rows flex:1 with align-items:center so items spread evenly instead of leaving an empty bottom.
- (b003) New ideas that worked: floor-plan grid (PG), myth-vs-fact with strikethrough, ticket-stub cards via CSS mask, marker whiteboard with red numbered rings. Next: try an isometric/3D-ish card stack, a big receipt mock, and a before/after slider handle.
- (b004) CTA slides with a peep keep coming out half empty at the top. Fix pattern: peep w~400 h~650 + option cards with 34-38px padding and 24-26px text; or add a scene object above (cloud/sun) in single-hero slides.
- (b004) Pure-CSS "henna" rings looked like tree rings. Small repeated motifs (dot + ring + conic rays, 64px tile, masked by the skin colour) read as a pattern; prefer tiled motifs over one big radial.
- (b004) 3D tilt (perspective + rotateX 24deg) on a data board passed check_text/check_gfx cleanly and added depth; pair it with a flat answer card overlapping the bottom edge.
