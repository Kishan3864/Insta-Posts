# Insta-Posts — Brighton Solution
Endless Instagram feed posts for @brighton.solution (websites, apps, custom software).
- `posts/NNNN_FORMAT_Market_Category/` → images (`1.jpg`... in upload order) + `post.md` (caption, hashtags, alt text).
- SINGLE = upload 1 image. CAROUSEL = upload all images together in order.
- Rules and process: `RUNBOOK.md`. Tools: `tools/postkit/`. Targets: `targets.txt`. Progress: `state.json`.
